Create and track playtest for a feature.

Read `skills/playtest/SKILL.md` for the full procedure.

Arguments: $ARGUMENTS (feature ID)

1. Resolve feature
2. Read acceptance criteria from spec
3. Check if Unity MCP or automation is available
4. If automation available: run automated checks
5. Create manual checklist for remaining items
6. If no automation: create full manual checklist
7. Track completion
8. Update feature status to PLAYTEST

CRITICAL: Never claim automated validation happened when it did not.
